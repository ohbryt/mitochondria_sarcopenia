# PPM1K–BCKDK–BCKDH manuscript package v1.0

This frozen package accompanies the integrative translational manuscript on
the PPM1K–BCKDK–BCKDH axis in sarcopenia. It contains the complete manuscript,
two conceptual figures, the four prespecified target audits, and the dataset
and modality inventories used to define the human evidence boundary.

## Package contents

- `manuscripts/ppm1k_bckdk_bckdh_v1.0.md` — complete manuscript.
- `figures/graphical_abstract_ppm1k_bckdk_bckdh.png` — graphical abstract.
- `figures/ppm1k_bckdk_bckdh_evidence_ladder.png` — evidence ladder.
- `supplementary/target_audits/` — exact cohort rows, replication rows, claim
  status, and input hashes for PPM1K, BCKDK, BCKDHA, and BCKDHB.
- `supplementary/dataset_audit.csv` — structured dataset inclusion audit.
- `supplementary/modality_detected.csv` — structured modality inventory.
- `cover_letter.md` — journal-agnostic submission letter draft.
- `manifest.tsv` — SHA-256 and byte size for every other file in this package.

## Claim boundary

This package does not claim a newly validated human drug target. The external
human multi-omic and preclinical literature prioritizes the pathway, whereas
the independent HMSR audit does not replicate any of the four individual axis
transcripts. The proposed advance is an activity-first validation programme
based on p-BCKDHA Ser293, isotope-resolved BCAA flux, genetic dependence,
mitochondrial competence, and donor-level muscle force.
